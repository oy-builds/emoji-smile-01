# One Emoji, One Smile — 🌞

A single-emoji entry for the make.fun "One Emoji, One Smile" bounty. The
program in `main.ts` writes exactly one emoji to `/output/entry.txt`: the
sun with a face 🌞 — a smiling burst of sunshine that reads as warmth at
first glance to any stranger, chosen deliberately over the default smiley
and free of any intimacy, irony or flirtation.

Run it with Node 22 or later:

```
node main.ts
```
